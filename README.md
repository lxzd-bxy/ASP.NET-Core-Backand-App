## 📖 О проекте

Это мой личный сайт-портфолио, созданный для демонстрации моих навыков и проектов в области веб-разработки. Проект представляет собой backend-приложение, построенное на платформе ASP.NET Core, и включает в себя сервис авторизации с refresh и access токенами.

Цель этого проекта - не только представить мой опыт, но и показать мой подход к разработке, использованные архитектурные решения и знание современных технологий .NET.

## 🛠️ Технологический стек

Проект построен с использованием следующего стека технологий:

-   **Backend**: ASP.NET Core 10, C#, MediatR 
-   **База данных**: PostgreSQL + Entity Framework Core
-   **Аутентификация**: ASP.NET Core Identity / JWT
-   **Документация API**: Swagger / OpenAPI
-   **Инструменты**: VS Code, Git, Docker
