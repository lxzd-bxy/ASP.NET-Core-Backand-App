# Auth.app

На данном этапе разработки проект существует для практики разработки авторизации в приложении на платформе ASP.NET Core.

### Используемые библиотеки

- MediatR
- EF Core (Npgsql)
- ErrorOr
- FluentValidation
- Identity
- JWT Bearer

### Дизайн

#### Архитекура

- Clean Architecture

#### Паттерны проектирования

- DI
- Repository
- CQRS

#### Принципы

- SOLID

> [!NOTE]
> У данного проект есть свой [Frontend](https://github.com/lxzd-bxy/online-store-client).
> Это приложение является второстепенным, основной проект будет заниматься обработкой криптоплатежей.
